Our Mission & Purpose

About Apla Shetkari

"Smart Farming, Better Future." – Bridging the gap between cutting-edge agricultural artificial intelligence and India's grassroots farming community.

Dedicated to Indian Farmers

Agriculture is the backbone of India's economy, supporting over 50% of the country's workforce. Yet, smallholder farmers face monumental challenges: irregular monsoon rainfall, volatile commodity prices, evolving pest resistance, and misleading chemical recommendations that increase input costs without guaranteeing yields.

Apla Shetkari (आपला शेतकरी) was designed to serve as a reliable, honest, and scientifically grounded virtual Krishi extension officer. Accessible directly from any smartphone or computer in Marathi, Hindi, and English, it puts the combined wisdom of agricultural agronomy right into the farmer's hands.

Key Philosophy: Never invent untested chemical dosages; prioritize Integrated Pest Management (IPM), soil testing, and balanced nutrition, and advise physical visits to local Krishi Vigyan Kendras (KVK) for epidemic situations.

Core Project Goals

Language Democratization

Provide guidance in regional languages (मराठी, हिंदी, English) with voice recognition for effortless interaction.

Micro-Climate Adaptation

Crop recommendations customized to Indian states, soil types (Black cotton, Alluvial, Red), and water availability.

Input Cost Reduction

Help farmers avoid unnecessary fertilizer overuse and unneeded pesticide sprays through precision advice.

Architecture & Engineering

Technology Stack

Built strictly adhering to clean, production-grade web technologies without heavy client-side frameworks.

Python & Flask Framework

Lightweight, modular backend handling authentication, parameterized SQL queries, secure sessions, rate limiting, and API proxying.

SQLite Database

Relational storage tracking users, encrypted credentials, conversation histories, and saved crop recommendation analyses.

Google Gemini AI Engine

State-of-the-art LLM fine-conditioned with strict Indian agronomic guidelines for safe, realistic, and multilingual responses.

HTML5, CSS3 & JavaScript

Handcrafted responsive interface, mobile drawer navigation, markdown parsing, and Web Speech API voice recognition.

Security & Integrity

Werkzeug password hashing, environment variable isolation, input validation, and SQL injection prevention.

Agronomy Alignment

System prompts formulated following ICAR and Krishi Vigyan Kendra extension recommendations for Indian farming realities.

College Project & Technical Demonstration

This project demonstrates full-stack software development, RESTful architectural design, relational database modeling, and real-world generative AI integration tailored to solve societal and agricultural challenges.
